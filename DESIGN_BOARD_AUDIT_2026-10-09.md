# Аудит доски «Дизайн мира» — 9 октября 2026

Проверены исходники всего `src/design/`, интеграция с представлением Obsidian, настройки и стили. Особое внимание уделено новым таблицам, спискам задач, колонкам, карточкам рисования, ссылкам, нижней/боковой панели и Markdown-экспорту. Найденные ниже ошибки исправлены, без отката остальных изменений проекта.

## Исправления

| Область | Ошибка и результат исправления |
| --- | --- |
| Перенос между досками | Источник удалял объекты до успешной записи назначения. Теперь назначение сначала сохраняет принятые объекты; при ошибке, конфликте или режиме «только чтение» источник их сохраняет. |
| ID при переносе | Повторный перенос после отмены мог добавить совпадающие ID. Назначение получает новые ID объектов, групп, связей и подписей; ссылки на записи остаются прежними. |
| Вставка в таблицы | Событие вставки из ячейки перехватывал холст и создавал отдельный текстовый объект. Ввод в ячейки и другие редакторы теперь использует обычную вставку. |
| Системный буфер | Копирование полагалось на асинхронную запись простого текста и могло терять структуру при быстрой вставке. Нативное событие копирования передаёт структурную копию вместе с текстом; для WebView без события есть резервный обработчик. |
| Свободные линии | Копирование выбранной линии пропускало невидимые концы; экспорт выделения пропускал саму линию. Теперь копируются концы, линия и подписи. Ctrl+A включает линии, перемещение стрелками переносит свободные концы, вписывание выделения работает. |
| Рамки | Копия рамки не включала содержимое, а вырезание оставляло его на старом месте. Копирование и вырезание теперь включают содержимое рамки и внутренние связи. |
| Только чтение | Редактор подписи линии, кнопки отмены и импорт вложений обходили общую проверку. Эти пути закрыты; инструментам, создающим объекты или вложения, выставляется недоступность. |
| Блокировка | Таблицы показывали активные поля даже при блокировке, а соседняя колонка могла сдвинуть заблокированные карточки. Поля блокируются, заблокированные карточки не сдвигаются. |
| Расстановка колонок | Повторная сортировка сравнивала указатель с уже сдвинутыми соседями. Позиции соседей для определения порядка теперь берутся из начала перетаскивания. |
| Отмена жеста | `pointercancel` очищал указатель, но оставлял изменённые координаты и рисунки после стирания. Состояние изменяемого жеста восстанавливается из снимка. |
| Поворот | Поиск объекта под концом линии и рисование на карточке не учитывали поворот. Проверка попадания и координаты рисунка используют локальную систему карточки; скрытые дети свёрнутой колонки исключаются из попаданий. |
| Концы линий | После перемещения конца оставались неиспользуемые невидимые объекты. Они удаляются; свободный конец привязывается к центру своего невидимого объекта. |
| Двойной клик подписи | Завершение нажатия во вновь открытом поле могло повторно создать подпись. Обрабатывается только указатель, для которого холст начал жест; двойной клик сбрасывает предыдущий тап. |
| Сетка и группы | Каждый член группы округлялся отдельно, меняя расстояния между объектами. Привязка теперь вычисляет общий сдвиг группы. |
| Размеры | Shift при уменьшении боковым маркером не уменьшал объект. Масштаб выбирается по изменяемой стороне с соблюдением обоих минимальных размеров. Числовые значения проверяются до сохранения. |
| Мобильная панель | Боковая панель перекрывала карточки; после её прокрутки касание иногда не включало инструмент. На узком экране панель расположена снизу, активация касанием обрабатывается при отпускании и защищена от повторного `click`. Обработчики панели удаляются при закрытии. |
| Формулы | Огромные диапазоны и многократные ссылки на одну формулу могли заблокировать UI. Диапазоны ограничены существующими ячейками; зависимости кэшируются, сложность и глубина ограничены. Ошибочные/слишком сложные формулы показывают `#ERR`. |
| Копия доски | Копия из хаба могла пропустить правки до автосохранения. Берётся текущий черновик открытого сеанса, а снимок фиксируется до асинхронного создания файла. |
| Предупреждения | Удаление повреждённой доски оставляло предупреждение, которое продолжало блокировать синхронизацию связей. Предупреждение удаляется вместе с файлом и при его переименовании. |
| Экспорт | SVG терял заголовки, зачёркивание, выравнивание абзацев и цветные полосы. Они сохраняются. Markdown распределяет содержимое по вложенным рамкам, включает все подписи линии и использует полные пути заметок/досок вместо неоднозначных названий. |

## Проверка

- Полный `npm test`: **64 файла, 521 тест**, все прошли.
- `npm run build`: успешная проверка TypeScript и сборка `main.js` в установленной папке плагина.
- `npm run check`: Svelte — **0 ошибок, 0 предупреждений**.
- `design-audit-verify.mjs`: **12 сценариев**, все прошли. Включены нативная вставка в ячейку, ошибка записи назначения, блокировка, отмена жеста, повёрнутое рисование, копирование линий/рамок и доверенные события касания.
- `design-parity-verify.mjs`: **8 групп проверок**, все прошли: форматированный текст, группы, размеры, линии, буфер, mind map, шаблоны, SVG/PNG/PDF и мобильное форматирование.
- `design-verify.mjs`: сохранение записей, управляемые ссылки, конфликты, вложенные доски, схема, удаление, жесты и мобильная панель прошли. Сцены с 500 объектами и 500 карточками показали медиану около 16,7 мс (60 FPS) в этом стенде.

Браузерные проверки используют Chrome и vault в памяти. Пользовательские заметки и доски не изменялись проверками. Отчёты и снимки находятся в исключённой из Git папке `tests/browser/design-results/`. Реальный Obsidian Mobile на Android и работа в запущенном Obsidian в этом аудите не проверялись.
