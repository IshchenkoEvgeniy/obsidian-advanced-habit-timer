# Таблицы мира: реализовано 2026-10-10

Обновлённое оформление, удаление галереи и сравнение с Miro/Milanote: [отчёт](DESIGN_BOARD_VISUAL_REWORK_2026-10-10.md).

## Где открыть

- **Проекты → Таблицы мира** у проекта, выбранного в настройках дизайна мира.
- **Дизайн мира → Таблицы мира** — те же записи и представления.
- На доске — инструмент **Таблица мира**; из таблицы — **На доску…**.

Основной **План разработки · GitHub** сохраняет этапы, задачи, подзадачи и существующие представления. Его источник, состояние и GitHub-привязки не заменяются данными мира.

## Таблицы и поля

Каждый тип мира является отдельной таблицей со своими полями. При первом открытии создаются виды «Таблица», «Канбан», независимое поле «Подготовка записи» и отдельный тип «Оружие». Старые записи не пересоздаются.

**Новая таблица** создаёт тип и открывает редактор полей. **Поля таблицы** позволяет переименовать тип, изменить его поля и параметры. Удаление типа сохраняет заметки: они остаются в обычном списке записей без известного типа.

Оружие из «Предметов» переносится только явно: выбрать записи галочками, **Перенести в таблицу… → Оружие**. Сохраняются `design_id`, текст, неизвестные поля и ссылки карточек. Обязательные поля нового типа проверяются перед сохранением.

## Представления

- **Таблица:** редактирование текстов, чисел, списков, дат, флажков, путей изображений, ссылок на записи и задачи. Нажать ячейку, изменить значение, ✓ сохранить или × отменить. Enter и уход из поля сохраняют значение, Escape отменяет. Tab/Shift+Tab сохраняют и перемещают фокус. Статус связанной задачи доступен только для чтения.
- **Канбан:** колонки по выбранному полю одного варианта (`select`). Перенос меняет это поле исходной заметки. На телефоне доступен список колонок на карточке. Пустые и неизвестные варианты остаются в «Не указано». Создание в колонке подставляет её значение.
Галерея удалена. Старые виды преобразуются в таблицы с сохранением ID и ссылок.
- **Вид:** имя, представление и обложка канбана. **Фильтр**, **Сортировка**, **Столбцы** и **Группы** открывают отдельные панели настройки. Заголовок колонки переключает сортировку; границу можно перетаскивать для изменения ширины.
- **+ рядом с видами:** новое сохранённое представление текущей таблицы. Удаление вида не удаляет записи; последний вид удалить нельзя.

Поиск учитывает поля и текст заметки. Однозначные фильтры равенства подставляются при создании. Если новая запись не соответствует условиям вида, интерфейс сообщает об этом.

Избранные таблицы и порядок таблиц сохраняются. Ручной порядок записей хранится отдельно для каждого вида; стрелки порядка доступны без поиска, фильтра и явной сортировки.

Отображаются первые 100 строк/карточек, для канбана — на колонку. «Показать ещё» открывает следующие. Поиск, фильтры, сортировка и счётчики работают по всей таблице. Редакторы списков и ссылок создаются только при открытии ячейки.

## План и GitHub

Поле `task` хранит ID задачи разработки. Название отображается вместе с этапом; задачу можно открыть из ячейки или панели записи. Для записи без связанной задачи доступно **Создать задачу по записи**: выбрать этап и создать локальную задачу плана со ссылкой на запись мира.

«Подготовка записи» — самостоятельное состояние дизайна. Поле `status` показывает **Статус реализации** связанной задачи. Канбан подготовки не меняет выполнение задачи. Удаление связи очищает сохранённый статус задачи.

GitHub Projects/Issues остаётся у плана этапов вместе с задачами/подзадачами. Мир использует `DesignService` и Markdown-записи, не `ProjectTask` и не поля GitHub. Парсер задач исключает записи с `design_id` из папочных и файловых источников. Обработчик синхронизации отказывает при выборе заметки мира как источника GitHub. Переключение таблиц и редактирование мира не вызывают GitHub.

Обычная синхронизация файлов vault и его резервное копирование через Git продолжают работать.

## Доска и телефон

Блок вида хранит ID типа и представления, показывает предварительный просмотр и открывает полноценный редактор. Копирование/удаление блока не копирует и не удаляет записи. Экспорт доски включает снимок данных вида.

При удалении вида блок показывает отсутствие источника. После удаления вида добавление нового блока использует ID фактически показанного оставшегося вида; обнаруженная при тестировании устаревшая ссылка исправлена.

Для доски в режиме чтения блокируются редактирование записей, создание, перенос и изменение конфигурации. Поиск и открытие источников остаются доступны.

На узком экране список таблиц открывается меню, редактор записи занимает доступное окно, а рабочую область можно вынести на весь экран. Полноэкранное окно учитывает системные отступы Android/iOS и visual viewport при клавиатуре. Выход возвращает тот же экземпляр в исходную панель.

## Хранение и конфликты

Канонический реестр типов и видов: `<корень дизайна>/world-tables.json`, версия 1. Он синхронизируется вместе с vault. `settings.design.types` остаётся совместимой копией; при наличии реестра схема читается из него. Корень и привязка к проекту остаются настройками плагина.

Первое открытие переносит существующую схему без пересоздания записей. Повреждённый реестр или неизвестная версия не заменяются стандартными. ID записей, типов, полей и видов не зависят от отображаемых названий.

Запись реестра проходит очередь и сравнение исходного текста. Внешний конфликт подгружает файловую версию и сообщает об ошибке. Устаревшие черновики схемы/вида отклоняются. Правки записи проверяют исходный Markdown. Удалённый вариант списка не мешает редактировать другие поля старой записи.

Старые версии плагина не знают объект `world-view` и не откроют доску с таким блоком: обновить плагин на остальных устройствах перед редактированием таких досок. Старые доски без новых блоков продолжают работать.
