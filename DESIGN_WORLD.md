# Дизайн мира

Модуль для заметок и свободных досок внутри Advanced Habit Timer & Stats. Данные создаются в vault через API Obsidian. Новых зависимостей и изменений версий нет; `isDesktopOnly` остаётся `false`.

## Начало работы

Таблицы, канбан и галерея записей мира: **Проекты → Таблицы мира** или вкладка **Таблицы мира** в хабе. [Описание реализации и проверки](DESIGN_WORLD_TABLES_IMPLEMENTATION_2026-10-10.md).

1. Перезагрузите плагин в Obsidian.
2. Откройте команду **«Дизайн мира: открыть хаб»**, значок `network` на ленте или раздел «Дизайн мира» в навигации плагина.
3. В **«Типы и поля»** проверьте корень хранилища и выберите проект для чеклиста. По умолчанию проект определяется по названию или пути `Factory Farm Dungeon Mining`.
4. Создайте записи и доску. На доске кнопка `+` создаёт запись, «Выбрать запись» вставляет существующую.

Корень по умолчанию: `Projects/Factory Farm Dungeon Mining/Дизайн мира`. Папки создаются при первом сохранении. Исходники и собранный `main.js` находятся в `obsidian-habit-timer-main`: это единственная папка в данном vault с manifest id `obsidian-advanced-habit-timer`; отдельной папки с именем id нет. Путь существующей сборки сохранён.

## Что доступно

- Девять стартовых типов, редактор типов и полей, порядок, обязательность, цветные варианты, ограничения чисел, импорт JSON и экспорт схемы в vault.
- Хаб записей с поиском и фильтрами по типу, тегу и статусу; раздел «Без типа». Создание, редактирование полей и Markdown, просмотр, открытие обычной заметки, переименование и удаление через корзину Obsidian.
- Доски: записи, стикеры, десять фигур, текст, изображения, PDF и другие вложения из vault, рамки, стрелки, рисование, ластик и ссылки на другие доски.
- Текст на холсте: ввод сразу после создания, двойным нажатием или Enter; форматирование выделенного фрагмента, жирный, курсив, подчёркивание, размер и цвет шрифта, выравнивание, списки и вложенность, ссылки. Esc или «Готово» завершает редактирование.
- Группы, блокировка, поворот, восемь маркеров изменения размера, сохранение пропорций с Shift, выравнивание и распределение, направляющие для нескольких объектов. Слои целиком и на один шаг, дублирование, вырезание, копирование между досками и перенос стиля.
- Оформление фигур и линий: заливка, цвет и толщина обводки, пунктир, прозрачность. Несколько подписей линии редактируются на холсте и перетаскиваются; точки изгиба можно двигать и сбрасывать. Доступны привязки к сторонам и центру, свободные концы линии; Shift задаёт направление через 45° для свободного конца.
- Перо, маркер и хайлайтер; ластик целыми штрихами или частями. Импорт картинок и текста из системного буфера, перетаскивание файлов, замена и обрезка изображений, библиотека иконок Obsidian и эмодзи.
- Поиск следующего совпадения на доске и поиск по всем доскам в хабе, сетка, привязка, миникарта, цвет фона, вписывание всего или выделения, масштаб клавиатурой, обход объектов и рамок.
- Режим карты мыслей: Tab создаёт ребёнка, Enter — соседнюю ветку; после ввода текста завершите редактирование. Автораскладка, шаблоны механики и сюжета, просмотр рамок как слайдов и копирование всей доски.
- Экспорт доски или выделения в SVG, PNG и PDF с изображениями, встроенными из vault. Файлы сохраняются под корнем модуля в `Exports/`.
- 120 шагов отмены/повтора на каждый открытый сеанс доски, включая переходы между вложенными досками.
- Одиночный клик или тап выделяет карточку. Двойной клик или двойной тап открывает запись либо вложенную доску; это также доступно кнопкой в панели действий. Два пальца — прокрутка и щипок; долгое нажатие — действия и добавление объектов к выделению. На узком экране панель инструментов находится снизу.
- Задача чеклиста и статус канбана доступны для чтения. Карточка показывает текущий статус; при сохранении записи в frontmatter сохраняется снимок статуса выбранной задачи. Модуль не вызывает мутации задач или GitHub-синхронизацию.

При масштабе ниже 30% карточки показывают заголовок и цвет; поля возвращаются при приближении. Геометрия сохраняется. Слишком мелкая сетка в этом режиме скрывается. Объекты вне экрана не создают карточек в DOM.

## Клавиатура и работа с объектами

Полный список открывается кнопкой «Горячие клавиши» в меню `⋯`, клавишей F1 или `?` при фокусе на холсте. Основные команды:

| Действие | Клавиши |
| --- | --- |
| Инструменты выделения, руки, текста, стикера, фигуры, линии, рамки, пера, ластика | V, H, T, N, S, L, F, P, E |
| Редактировать / закончить ввод | Enter / Esc |
| Форматировать выделенный текст | Ctrl+B / Ctrl+I / Ctrl+U |
| Вставить ссылку в текст | Ctrl+Alt+K |
| Группа / разгруппировать | Ctrl+G / Ctrl+Shift+G |
| Блокировка / разблокировка | Ctrl+Shift+L |
| Вырезать, копировать, вставить | Ctrl+X, Ctrl+C, Ctrl+V |
| Дублировать | Ctrl+D, Alt+перетаскивание, Alt+стрелка |
| Передвинуть объект | Стрелки: 1 px; Shift+стрелки: 10 px |
| Следующий / предыдущий объект | Tab / Shift+Tab |
| Ближайший объект по направлению | Ctrl+стрелка |
| Войти в рамку / выбрать внешнюю рамку | Ctrl+Shift+↓ / Ctrl+Shift+↑ |
| Масштаб, 100%, всё, выделение | Ctrl+ / Ctrl− / Ctrl+0 / Alt+1 / Alt+2 |
| Поиск, следующее / предыдущее совпадение | Ctrl+F, Enter / Shift+Enter в строке поиска |
| Миникарта / сетка | M / G |
| Слой на один шаг | PgUp / PgDn |
| Очистить текст объекта | Ctrl+Backspace |

Команды относятся к холсту с фокусом. Во время ввода текста стрелки, копирование, вставка и отмена работают в редакторе. Ctrl можно заменить Cmd на macOS. Вставка из системного буфера зависит от доступности Clipboard API или события вставки в WebView; внутренняя копия объектов сохраняется между досками.

Список команд сопоставлен с [официальной справкой Miro](https://help.miro.com/hc/en-us/articles/360017731033-Shortcuts-and-hotkeys); здесь PgUp / PgDn перемещают объект на один слой, как указано в задании.

## Предложенные стартовые поля

| Тип | Основные поля |
| --- | --- |
| Персонажи | Роль, локация, уровень, характер, портрет, фракция |
| Локации | Биом, опасность, описание |
| Механики | Условие запуска, правила, стоимость |
| Предметы | Категория, значение, размер стопки, рецепт |
| Враги | Здоровье, урон, локация, поведение |
| Фракции | Цель, лидер, отношения |
| Сюжет | Глава, локация, план |
| Баланс | Показатель, значение, цель, формула |
| Идеи | Категория, приоритет, описание |

У каждого типа также есть теги, ссылка на задачу и статус. Это начальное предложение: названия и наборы можно изменить в редакторе. ID типов и полей постоянны. Тип заполненного поля менять нельзя, включая импорт JSON; ошибка указывает тип записи и поле. Удаление схемы или типа не удаляет заметки и их данные. Изменение папки типа влияет на новые записи; существующие заметки автоматически не перемещаются.

Стандартный приоритет идеи хранится как `low`, `medium`, `high`, а подписи переводятся на язык интерфейса. При первом открытии старые стандартные варианты и значения «Низкий», «Средний», «Высокий» / `Low`, `Medium`, `High` мигрируют в эти ID. Пользовательские варианты сохраняются.

## Хранение и конфликты

Одна запись — одна Markdown-заметка с `design_id`, `design_type` и полями во frontmatter. Длинные поля находятся под заголовками `##`; служебный маркер постоянного ID сохраняет содержимое при переименовании поля. Схемы находятся в настройках плагина.

Доски хранятся в `Доски/*.board.json`, формат 2. Форматы 0 и 1 мигрируют при чтении без удаления объектов и связей; следующая пользовательская правка сохраняет формат 2. Неизвестные будущие форматы не перезаписываются. Открытие и автоматическое измерение карточек не запускают сохранение. Вычисленный размер сохраняется вместе со следующей пользовательской правкой.

Новые поля объектов: `richText`, `textStyle`, `groupId`, `locked`, `rotation`, обводка, прозрачность, обрезка и `mindParent`. Линии сохраняют цвет, толщину, пунктир, массив подписей и точек изгиба. Подписи имеют позицию на линии и смещение; при переносе связанных объектов они остаются с линией. Название доски сохраняется полностью; ограничения файловой системы применяются к имени файла.

`richText` содержит HTML с ограниченным набором тегов: форматирование текста, абзацы, списки, ссылки и безопасные стили текста. При выводе и вставке удаляются скрипты, обработчики событий, встроенные объекты и опасные URL. Форматирование текста доски не меняет Markdown записей.

Автосохранение с задержкой 500 мс использует атомарный `Vault.process` и проверяет исходный текст. Чистая доска перечитывает внешние изменения; при несохранённых правках появляется выбор версии. При закрытии конфликтного сеанса локальные правки сохраняются в отдельную восстановительную доску с новым ID. Удаление доски закрывает её сессии и возвращает активный экран в хаб. Чистый редактор записи обновляется при синхронизации связей; несохранённые правки сохраняются до явного разрешения конфликта.

Стрелки между записями создают ссылки от начала к концу в отмеченном блоке секции `## Связи`. Наконечники, включая два наконечника, меняют только внешний вид. Ручные ссылки и примеры маркеров внутри блоков кода сохраняются. Связь учитывается по всем доскам: она исчезает после удаления последней соответствующей стрелки. Изменение раскладки не читает заметки из vault. При изменении связей, имени или пути целевой записи обновляются только затронутые заметки.

Дубликаты ID и повреждённые доски показывают предупреждение и приостанавливают всю синхронизацию управляемых ссылок: добавление и удаление. После устранения ошибки синхронизация возобновляется при следующем сохранении доски или изменении файлов.

## Проверка

Исправления цвета и размера текста, выделения, истории и системных отступов Android от 10 октября 2026 описаны в `DESIGN_BOARD_TEXT_SAFE_AREA_AUDIT_2026-10-10.md`. Новые браузерные проверки: `design-text-verify.mjs` и `design-safe-area-verify.mjs`.

Мобильная раскладка и аудит от 10 октября 2026 описаны в `DESIGN_BOARD_MOBILE_AUDIT_2026-10-10.md`. Полноэкранный режим открывается кнопкой справа от названия доски; свойства и все инструменты открываются отдельными панелями. Новый прогон — `node tests/browser/design-mobile-verify.mjs`.

Обновление по образцу Milanote от 10 октября 2026 описано в `DESIGN_BOARD_MILANOTE_2026-10-10.md`: упорядоченные колонки, неразобранное каждой доски, сохраняемая корзина, превью ссылок, обрезка и разметка изображений, карточки Board с обложкой/эмодзи и обновлённая боковая панель. Новый браузерный прогон — `node tests/browser/design-milanote-verify.mjs`.

Исправления по результатам аудита от 9 октября 2026 описаны в `DESIGN_BOARD_AUDIT_2026-10-09.md`. Дополнительный браузерный прогон: `node tests/browser/design-audit-verify.mjs`. Таблицы поддерживают обычную вставку в ячейки, а вычисление формул ограничено существующими ячейками и допустимой сложностью.

Команды проекта: `npm test`, `npm run build`, `npm run check`. Новые проверки покрывают схемы и все типы полей, форматы и миграции, историю, общий ID, переименование, управляемые ссылки, конфликты и восстановление.

Браузерный стенд: `node tests/browser/design-board.mjs`, затем `node tests/browser/design-verify.mjs` и `node tests/browser/design-parity-verify.mjs` при доступном Playwright и Chrome. Стенд работает только с данными в памяти, не изменяет заметки vault и не использует пользовательский профиль браузера. Результаты и снимки: `tests/browser/design-results/`; они исключены из Git.

Проверены Chrome и мобильная эмуляция 390×844, включая настоящие события касания для выделения, открытия, создания, перемещения, рисования и форматирования текста. Проверки паритета охватывают группы, блокировку, размеры, линии, поиск, mind map, шаблоны, презентацию, копию доски и экспорт с двумя картинками. Вставка картинок проверена событием ClipboardEvent; нативный Ctrl+X/Ctrl+V — для объектов. PDF дополнительно прочитан независимым парсером. UUID имеет резервную генерацию для WebView без `crypto.randomUUID`. Фактический Obsidian Mobile на Android и работа внутри запущенного Obsidian требуют проверки на устройстве. Производительность стенда не является гарантией для всех устройств.

SVG сохраняет векторную геометрию, встроенные картинки, разметку изображений, обложки Board и превью ссылок; текст экспорта использует Arial. PNG и PDF содержат растр доски. Растр ограничен 8192 px по длинной стороне и 16 миллионами пикселей, чтобы ограничить расход памяти на телефоне. PDF — одна страница. Для большого холста можно экспортировать выделение. Вложения показываются карточками с открытием исходного файла в Obsidian; локальные видео, аудио и PDF отображаются внутри карточек.

Запись статусов/отметок задач и домен Dashboard API `design` оставлены для следующей версии: основная часть ТЗ требует только чтение, API указан как опциональный.
