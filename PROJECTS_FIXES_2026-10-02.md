# Исправления после анализа общих заметок — 2026-10-02

Исправлены сценарии из `PROJECTS_AUDIT_AFTER_ROOT_NOTES_2026-10-02.md`. Этот документ описывает изменения исходников, а не результаты проверки в работающем Obsidian.

| Пункт | Изменение |
| --- | --- |
| 1. Идентичность | При согласовании сохраняются прежние ID checkbox-задач, физические block ID и маркеры этапов/групп. Дубли и устаревший исходный текст блокируют запись. |
| 2. Перенос описаний | Очередь очистки использует первоначальный снимок исходного раздела. Проверяется текст в месте назначения; изменившийся источник сохраняется. |
| 3. Одновременная запись | Создание, изменение, перенос, удаление, архивирование и вставка подзадач используют `vault.process`. Импорт и обновления GitHub также проверяют актуальность снимка. |
| 4. Описание | Редактор и GitHub проверяют ожидаемое описание перед override. Новая локальная версия вызывает конфликт. |
| 5. Внешние ссылки | В прежней заметке после переноса остаётся переадресация с прежним якорем. |
| 6. Загрузка | Активный проект публикуется сразу. Статистика остальных читает парсер без миграции; ошибки изолированы через `allSettled`. |
| 7. Вставка | Новая подзадача вставляется за полным Markdown-блоком, включая вложенный текст и картинки. Нумерация определяется по актуальному блоку. |
| 8. Сортировка | Заголовки не предлагают отменяемую сортировку при иерархии; подсказка объясняет порядок через перетаскивание соседних задач. |
| 9. Проверки полей | Создание, модальный редактор, inline-правки и Companion используют общий валидатор названия, статуса, оценки, дат, привычки, меток и приоритета. |
| 10. Companion | Удаление проверяет подпись корня, выбранные поля и подпись потомков, включая описания, метки, обложку, привычку и другие параметры. Старый снимок без подписи требует обновления. |

GitHub-описания при импорте и получении изменений записываются пакетом: одна операция состояния/индекса вместо отдельной операции на каждую задачу. Число чтений и записей сокращено по структуре кода; замеры времени не выполнялись.
